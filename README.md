# 📌 Mosom

## 📋 About the Project

Mosom is a mobile music recognition application that works similarly to Shazam, but with an important difference: in addition to identifying the song that is playing, it allows the user to download the track directly to their device.

## ✨ Features

- [ ] Music Recognizer & Downloader API
- [ ] Mobile App
    - [ ] Record Screen
    - [ ] Result Screen
- [ ] Tests

## 🛠️ Technologies

- FastAPI
- React Native
- TypeScript
- Python
